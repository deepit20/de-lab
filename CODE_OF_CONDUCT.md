# Code of Conduct

DE Lab is a learning project. Many contributors and users are beginners, career-changers or non-native English speakers — **be kind, patient and constructive.**

## Expected
- Assume good intent; explain rather than judge.
- Give specific, respectful feedback on code and content.
- Welcome first-time contributors.

## Not acceptable
- Harassment, insults, discriminatory language or personal attacks.
- Publishing others' private information.
- Spam or self-promotion unrelated to learning.

## Enforcement
Maintainers may edit or remove comments, issues and contributions that break these rules, and may block repeat offenders. Report problems privately to the maintainers via the contact on their GitHub profile.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
